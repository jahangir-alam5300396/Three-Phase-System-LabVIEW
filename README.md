# Three-Phase Electrical System Simulation using LabVIEW

⚡ This project simulates a three-phase power system using **LabVIEW** and **Arduino Mega**, focusing on signal generation, phase control, and real-time visualization.

## 📄 Project Report

[Download Full Report (PDF)](./Three-Phase-System-Report.pdf)

## 🔍 Overview

- Simulates sinusoidal signals with 120° phase shift
- Visualizes voltage and current waveforms in real-time
- Includes phase meter, oscilloscope, and dynamic control
- Implements Start/Stop logic using Boolean functions
- Uses Arduino input pins for signal variation

## 🧠 Tools Used

- LabVIEW
- Arduino Mega
- Virtual Instruments (VIs)
- Signal Processing Blocks

## 📊 Features

- Block diagram for three-phase input
- Oscilloscope for waveform display
- Case structure for phase angle conversion
- Front panel with phase meter readings
- Boolean logic for Start/Stop controls
